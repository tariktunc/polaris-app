## 🚀 Öne Çıkan Özellikler

* **🎯 Otomatik Tıklama Zoom'u**: Tıkladığınız pencereleri ve butonları algılar; keyframe uğraşı olmadan yumuşak zoom efektleri üretir.
* **✨ 120 Hz İmleç Düzeltme**: Fare hareketlerini sinematik akıcılıkla yumuşatır, tıklamaları parıltı halkalarıyla vurgular.
* **🎥 Dinamik Kamera Balonu**: Web kameranızı yuvarlak/kare baloncuk veya tam ekran modunda şık geçişlerle gösterir.
* **🎙️ Stüdyo Ses Senkronu**: Sistem sesini (WASAPI Loopback) ve mikrofonu video ile milisaniye hassasiyetinde hizalar.
* **🔇 Durgun Anları Silme**: Konuşmadığınız veya ekranda hareket olmayan ölü anları tek tıkla videodan çıkartır.
* **⚡ 4K, Dikey & GIF Çıktı**: 16:9 YouTube, 9:16 Shorts/Reels ve hareketli GIF formatlarında GPU hızlandırmalı dışa aktarma.
