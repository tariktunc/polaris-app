## 🚀 Key Features

* **🎯 Smart Click Auto-Zoom**: Detects active windows and clicks; generates smooth cinematic zoom motions without manual keyframing.
* **✨ 120 Hz Cursor Smoothing**: Cleans up jittery mouse movements with smooth sub-pixel curves and highlights clicks with ripple waves.
* **🎥 Dynamic Camera Bubble**: Positions your webcam as a circular/rectangular bubble or full-screen speaker with spring transitions.
* **🎙️ Studio Audio Sync**: Captures system audio (WASAPI Loopback) and microphone aligned to the first video frame to the millisecond.
* **🔇 Quiet Moments Removal**: Automatically detects and trims dead silent and inactive stretches in one click.
* **⚡ 4K, Vertical & GIF Export**: GPU-accelerated rendering for 16:9 YouTube, 9:16 Shorts/Reels, and palette-optimized animated GIFs.
